# 文書一覧と用途 / Documentation Guide

この目録では、各文書で分かることと原本の場所を、用途別に案内します。文書名が分かっていてすぐに開きたいときは、[文書ポータルのジャンプ一覧](https://soone-y.github.io/OPEN_PDF-Note-Workspace/#all-documents)も使えます。

This catalogue explains what each document covers and where its source is located, grouped by purpose. If you already know the document you want, use the [portal jump index](https://soone-y.github.io/OPEN_PDF-Note-Workspace/#all-documents).

日本語・英語の各版を掲載しています。文書名からブラウザ版を開けます。パスは、リポジトリで原本を探すための補助情報です。

Japanese and English versions are both listed. Document titles open the browser version on GitHub Pages. Paths help locate the original files in the repository.

## 更新時の順序 / Update order

1. まず各言語の `docs/ja/` または `docs/en/` にある正本を更新します。 / First update the canonical document in `docs/ja/` or `docs/en/`.
2. 共通の入手方法、ライセンス、セキュリティ方針はトップ文書を更新します。 / Update top-level documents for shared download, license, and security information.
3. この一覧と、公開・releaseのリンク検証を更新します。 / Update this map and the public/release link checks.

# 理念の根拠

　現状取り巻く学習環境は、情報技術の発展により、電子機器を利用した実物の無い利用しやすい環境へと移り変わってきた。デジタル化はアナログな物体を離れ、配布や閲覧を簡単にするメリットがある。一方で、受け取り手はその媒体を選べず、デジタル情報を閲覧する環境の用意を強いられる。この状況に潜む利用環境の空白は看過されてはならず、社会はその配布者自身も含めてこの問題を認識していなければならない。このプロジェクトは、この空白を埋める一助を為す。

　情報社会への移り変わりの身近な影響は、教科書のデジタル化や配布プリントの電子化、情報共有のアプリ化など数多くある。先に挙げた例では、いずれも配布元と受け取る人がいる。配布元が配布方法に最大の決定権を持つことも考えるに容易い。末端利用者が個別に方法を選べないことは、現実の社会であるために許容されるべき現状ではある。諸々の配布には複数の利害関係者がおり、加えて環境問題も考慮しなければならない現代社会に於いて配布者の責任による判断は尊重されるべきである。たとえ幾人かの受取手が実態のある特定の配布の仕方を望んでいても、配布者は最大多数の最大幸福を優先するのが世の傾向であろう。

　ところで、電子配布物の利用の仕方にも配布者は考慮しているだろうか。配布形式におけるPDFは、文書に関する統一されたフォーマットであり、多くの利用者に共通した文書データを共有することを可能にしている。しかし配布形式は全てではない。配布物を何で見るか、どう利用するかというような環境も利用者の体験を決定づける。例えば一般に選択される環境は、PDFでは一般にブラウザとなり、注釈機能の利用やメモ帳との併用によって使われるだろう。その利用の仕方については利用者に決定権があり、配布者がその全てを考慮するべきという主張は憂慮される。

　デジタルで配布された資料を利用する環境について話題にした。PC、スマートフォン、ブラウザ、メモ帳、Adobeなど様々あるだろう。資料を印刷し手間をかけて紙媒体にする利用の仕方もある。この利用の仕方については責任の所在があるだろうか。利用者は自由に選べるように思えるが、その選択肢は教えられているだろうか。

　私の例を述べればPCによって最初に利用した環境はMicrosoft Edge の注釈機能であった。テキストを打て、自由に線が引ける。もちろんPDFの閲覧も不自由無くできていた。しかしそこには問題があった。注釈で記したフォントは日本語ではなく、中国語の漢字フォントで描画されていた。加えてときどき注釈に記した文字が描画されなかった。この環境を受けて私は別の環境を探し、Google Chrome を利用しようとしたがテキスト注釈ができず利用を断念した。さらに探せば有料のソフトが選択肢に挙がる。以上が私の実体験である。このように利用しにくい現状の責任は誰にあるだろうか、いやない。誰にも責任がないからこそ、問題は誰にも是正されず不便は残りうる。社会の責任にすることもできるが、結局それは責任の所在を有耶無耶にするに等しく、状況は改善しない。

　ここまでの話をまとめる。情報利用の進む社会においてその仕方は配布者が決定する。利用の仕方は受取手が決められる。しかしその利用の仕方、選択肢は充実しているとは言い難い。文書として一般的なPDFを選んでも、利用の仕方は一様ではなく、最初に提供される利用の仕方も絶対に最適ではない。以上がまとめである。このような状況で、良い利用の仕方についての情報を大衆に知らせることは有効であるが、そもそも良い利用ができる環境がなければしようがない。その良いPDFの利用ができる環境を当プロジェクトは提供することで一連の問題を含む現状を是正する一助を為す。

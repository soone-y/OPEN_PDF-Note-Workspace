# Background, Design, and Verification Material

This is an English entry point for selected background, design, and verification material for PDF Note Workspace. For the software overview, packages, and Standard/Lite editions, read the [Project overview](../../README.md). For setup, use, saving, and recovery, read the [English user documentation](../../docs/en/README.md).

The translated documents below explain the purpose of the software, its principal features, and how files and saved data are handled. They are written for people first. Headings, tables, and structured notation also make the material easier to inspect and reference.

## Available in English

- [Project overview reference](project_overview.md) — facts, policies, limitations, and how to describe the project accurately
- [Features FAQ](features_faq.md) — principal functions, editions, local operation, and known limitations
- [File formats and persistence](file_formats.md) — the roles of PDFs, annotations, notes, and recoverable saved data

## Japanese reference material

## Reading carefully

- Distinguish verified facts, project policies, known limitations, inferences, and matters that have not been verified.
- GitHub Pages publishes documents, not the source code, tests, settings, or release binaries. Confirm those materials separately when a conclusion requires direct implementation evidence.
- Structured notation helps navigation but does not itself guarantee that a claim is correct. Return to the cited text and primary materials when needed.

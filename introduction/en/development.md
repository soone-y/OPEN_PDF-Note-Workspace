# Development Approach

This document describes the decisions and responsibility to explain that belong to the developer of this project. Its subject is distinct from the [reference material for an AI asked by a user to investigate the project](project_overview.md). A [Japanese version](../development.md) is also available.

The developer takes responsibility, beyond the published documentation, for explaining the ideas, principles, goals, and decisions to accept or reject proposals and implementation choices. When unable to explain immediately from their own knowledge, the developer investigates and checks the evidence, using AI if needed. The developer remains responsible for the answers and decisions when using AI.

The source code itself explains the application's processing. Behavior and bugs are examined based on the ideas, principles, and implementation, tracing how implementation corresponds to or differs from intent and where processing fails. Explanations distinguish established facts, inferences, and unverified points.

# ノートの書き方ガイド

まず早見表から書き方を選びます。詳しい手順・別名・組み合わせは後半にまとめています。

## 末尾の編集用余白

設定のノート欄、または右下の状態アシスト欄の「ノート下部の余白」から変更できます。固定値（100%表示時のpx）、文字サイズに対する割合、ノート表示領域の高さに対する割合を選びます。既定は固定32pxで、0にすると余白なしです。小さい表示領域では本文1行を残す高さに制限します。

構成表示では末尾より下へスクロールでき、入力・改行やカーソル移動の際も、カーソルの下に設定した余白を残す位置まで自動でスクロールします。ホイール操作だけではカーソルへ引き戻しません。原文表示では編集領域の下側に空間を確保します。本文に空行は追加せず、保存・出力内容も変えません。

## 全角記号で書く（.clro）

設定のノート欄に「CLRO装飾を半角に限定（日本語色名も無効）」があります。既定はOFFです。ONでは装飾タグの括弧・名前・等号・引用符・区切りに半角を使い、色は英語名またはRGB数値で指定します。`<c=red>`・`<c=#ff0000>` は使えますが、`＜ｃ＝赤＞`・`<c=赤>` は色装飾として解釈しません。本文やフォント名の日本語、保存原文は保ちます。この設定は `.clro` に適用します。

`.clro` の全角対応は装飾タグの記述に適用します。Markdownの見出し・太字・取り消し線・箇条書き・表・リンク・コード・コンテナは半角記号で書きます。本文の `～(例)`、`～～`、`＊＊` などは、そのままの文字として表示します。

既存の装飾タグも `＜u＞下線＜／＞`、`＜char＝＂red＂＞赤＜／char＞` のように、括弧・斜線・等号・引用符を全角で書けます。タグ名・属性名の英字も全角に対応し、`<ｃ＝赤>赤い文字</>`、`<Ｃ=赤>赤い文字</>`、`＜ｂａｃｋ＝薄黄＞背景＜／＞` と書けます。半角との混在や英字の大小文字にも対応します。本文、色名・フォント名・リンクIDなどの属性値、リンク先のパス、コード本文はそのまま扱います。例えば属性値の `ｒｅｄ` は色名の `red` とは別の文字列です。

数式の囲み・タグ・TeX記号は半角で書きます。`＄x＄` や `＼（x＼）` は数式にならず、数式本文の全角記号も半角へ変換しません。保存原文は入力した表記を保ちます。この全角記号の対応は `.md`・`.markdown`・`.txt` には適用しません。

Markdown出力では「全角の構文記号を半角に変換（CLRO → md）」が既定でONです。認識された装飾タグの記号・名前を半角にします。本文中の全角文字・コード本文・数式・リンク先・属性値は保ちます。OFFにすると元の表記で出力します。予約ごとにON/OFFを指定できます。HTML・TXTにはこの変換オプションを適用しません。

## 入力アシストで適用する

左下の入力欄に文字を入れ、書式を選んで「適用」またはEnter。既にある文字を整えるときは、入力欄を空にしてノートの文字を選択します。「箇条書き」「引用」「ページ参照」「PDFリンク」もこの欄から使えます。

この文書は「書き方ガイド」ボタンで開けます。ノート未選択でも利用できます。ノート形式には `.clro`・`.md`・`.markdown` を使います。

## 詳しい書き方

コード枠は、そのまま書くための例です。表示と原文を比べながら、必要な例をコピーしてください。

### 段落・見出し・区切り `M`

空行で段落を分けます。通常の改行は段落内の改行として扱います。明示的な改行は行末の半角空白2個、または行末の `\` で記述できます。表示上の折り返しは本文に改行を追加しません。

```text
# 大きな見出し
## 章
### 節
#### 小見出し
##### 細かな見出し
###### 最も小さな見出し

ひとつ目の段落。

次の段落。

---
```

見出しの `#` の後には半角空白を置きます。`***`・`___` も区切り線です。文字の下の `===` による見出しも扱いますが、`---` はこのソフトでは区切り線として扱います。見出しには `#` を使うと明確です。

### 箇条書き・番号・タスク・引用 `M`

```text
- 項目
- 次の項目
  - 入れ子の項目

1. 最初
2. 次

- [ ] 未完了
- [x] 完了

> 引用した文章
> 続き
>
> 引用の別段落
```

箇条書きは `-`・`*`・`+`、番号は `1.`・`1)` の形を使えます。記号の後には半角空白を置きます。入れ子は親の内容の位置へ字下げします。タスクの状態は原文の `[ ]`・`[x]`・`[X]` で指定します。引用内にも見出しや箇条書きを書けます。

### 行内の文字装飾 `M`

| 書き方 | 意味 |
| --- | --- |
| `**太字**`・`__太字__` | 太字 |
| `*斜体*`・`_斜体_` | 斜体 |
| `***太字と斜体***` | 太字と斜体 |
| `~~取消線~~` | 取消線 |
| `` `コード` `` | 行内コード。中の記法を解釈しない |
| `\*文字\*` | 記号を文字として書く |

強調記号と文章の間には空白を入れません。下線は独自装飾の `<u>文字</>` を使います。コード内にバッククォートがあるときは、外側をより長いバッククォートで囲みます。

### コード・記法の例をそのまま表示 `M`

以下の外側4個のバッククォートは、内側3個を含む例を表示するためのものです。ノートへコードを書くときは内側の3個から3個までを使えます。

````text
```text
**この中は太字になりません**
<char=ff0000>この中は色を変えません</>
$x^2$ も数式にしません
```
````

`~~~` のフェンスも使えます。開始・終了の記号は同じ種類とし、終了側は開始側と同数以上にします。開始行の `text` などは言語名の目印で、プログラムを実行する指定ではありません。4個の空白によるコードブロックは使わず、フェンスで囲みます。

### 表 `M`

```text
| 左寄せ | 中央寄せ | 右寄せ |
| :--- | :---: | ---: |
| 内容 | 内容 | 123 |
| 次の行 | **強調** | 456 |
```

ヘッダーの次に区切り行を置き、セルを `|` で分けます。セル内の縦線は `\|` と書きます。通常は列をそろえて表示し、表を編集するときは全体を原文表示します。幅が収まらないときは横スクロールで確認します。

### リンク・画像参照 `M`

```text
[別のノート](別のノート.md)
[空白を含む名前](<別の ノート.md>)
[資料][ref]

[ref]: 資料.md

![画像の説明](図.png)
```

通常のリンクと参照形式のリンクを記述できます。画像記法は説明文字と参照先として扱い、ノート本文に画像を埋め込んで描画する機能ではありません。URLを書いても通信・ダウンロードは行いません。リンクの表示と、アプリ内で移動できる対象は区別してください。

### 独自装飾をまとめて書く `c`

`<属性, 属性=値>文字</>` の形を使います。属性はカンマまたは空白で区切り、空白を含む値は一重・二重引用符で囲みます。基本の終了は `</>` です。入れ子では内側から閉じます。`</char>` など属性名の終了指定も使えます。コード・数式の内部では、通常の独自装飾を解釈しません。

| 属性・別名 | 記述例 | 意味 |
| --- | --- | --- |
| `u` | `<u>下線</>` | 下線 |
| `b`・`bold`・`strong` | `<b>太字</>` | 太字 |
| `i`・`italic`・`em` | `<i>斜体</>` | 斜体 |
| `x`・`s`・`strike`・`del`（値なし） | `<x>取消</>` | 取消線。`s=数値` は文字サイズ |
| `char`・`c` | `<char=赤>文字色</>` | 色名または6桁のRGB色。下の対応表を参照 |
| `back` | `<back=fff2cc>背景色</>` | 背景色 |
| `font`・`f` | `<font="Yu Gothic">文字</>` | フォント名。使用できるフォントは環境による |
| `s`（値あり） | `<s=24>大きな文字</>` | 文字サイズをpxで指定。`24px`・`+2`・`-2` も使える |
| `m` | `<m=5>広い行高</>` | 基準行高に0.1倍を5単位加える（1.5倍）。`m+0.5`・`m-0.5` は相対指定。値なしの `m` は+0.5単位 |
| `d`（整数） | `<d=2>字下げ</>` | 文字幅を基準とした字下げ |
| `d`（位置） | `<d=center>中央</>` | `left`・`center`・`right`。`<d="right -1">右端から1字分内側</>` のような補正も可能 |
| `l`・`link` | `<l=topic-a>リンク点</>` | ノート・PDFリンクの識別子 |
| `la`・`linkaccent` | `<l=topic-a, la>リンク</>` | リンクのアクセント色 |
| `lu`・`linkunderline` | `<l=topic-a, lu>リンク</>` | リンクの下線 |

```text
<char=1a73e8, back=fff2cc, u>複数の装飾</>
<font=Consolas><s=24>フォントとサイズ</></>
<back=fff2cc>外側 <u>内側</> 外側へ戻る</>
```

### ノート・PDF間のリンク `c`

同じ識別子の位置どうしを結ぶ独自のノートリンクは次の形です。`link` の短縮形は `l`。`la` はアクセント色、`lu` はリンクの下線です。

```text
<link=topic-a, la, lu>移動元</>

<link=topic-a>移動先</>
```

PDFの特定位置と結ぶには入力アシストの「PDFリンク」を使い、PDF側とノート側に対応するリンク点を作ります。ノートの識別子だけを書いてもPDF側のリンク点は作られません。「ページ参照」はページ番号の文字であり、この位置リンクとは別の操作です。

### 囲みブロック `c`

```text
::: note
**補足**の文章。

内部にも箇条書き、表、数式を書けます。
:::
```

開始・終了は単独行に置き、開始行の文字をタイトルとして表示します。本文には他の記法も使えます。

### 数式の区切り `c`

数式はTeXの一部に対応する試験的な機能です。文章中は `$...$`・`\(...\)`、独立した数式は `$$...$$`・`\[...\]` を使います。

```text
速度は $v = \frac{d}{t}$ です。

$$
E = mc^2
$$

\(a_1 + a_2\)

\[
\sqrt{x^2+y^2}
\]
```

Markdown系ノートでは `<math>...</math>` または `<math>...</>` も使えます。文章中なら行内、文章がない単独の囲みなら独立数式です。`display=inline`・`display=block` で指定でき、値は引用符でも囲めます。開始タグは1行に書きます。

```text
式は <math>E=mc^2</math> です。

<math display="block">
\frac{1}{2}
</math>
```

## 発展的な書き方・詳しい仕様

### タイトルと入れ子 `c`

開始行を `` ```cpp title="example.cpp" `` とすると、言語名と別にタイトルを表示します。タイトルは文字として表示し、中の記法を解釈しません。

開始・終了は単独行に置きます。開始行の `note` などの文字はタイトルとして表示し、`::: note title="注意事項"` でタイトルを明示することもできます。`title=""` はタイトルを表示せず、不正な引用符や重複した `title=` でもタイトルを表示しません。

名前付きの開始を内部に置けば入れ子になります。名前なしの `:::` でも開始でき、終了行は開始と同数以上のコロンを使います。行頭空白は3個までです。閉じ忘れは文書末尾まで続きます。タイトルは文字として表示し、折り畳みやCSS装飾の指定ではありません。

### 属性の細かい指定 `c`

色の `#` は省略できます。色を `hicont`・`hi-contrast`・`highcontrast`・`high-contrast` と指定すると、読みやすさを優先する高コントラスト色を使います。真偽値を受ける装飾は `u=1`・`b=true`・`i=on`・`lu=yes` などでも有効にできます。`false`・`0` は外側の装飾を打ち消す指定ではありません。文字サイズは6〜256px、行高の追加量は0〜60単位の範囲へ収めます。未知の属性を、任意のHTMLやCSSのようには使えません。

### 互換用の見出し・範囲の終了 `c`

既存ノートとの互換のため、単独行の `<h1>見出し</>`〜`<h6>見出し</>` も見出しとして扱います。見出しに伴う字下げ・装飾の範囲を閉じるには、その階層の `</#>`・`</##>` などを使えます。通常のノートではまずMarkdownの見出しを使ってください。

### 数式タグの属性と注意点 `c`

`math` タグの名前・属性名・表示種別は大文字小文字を区別しません。閉じ忘れ・入れ子・不正または重複した `display` は原文を残します。未知の属性は表示に反映しません。行内数式は1行で書き、ブロック数式の前後に文章を置きません。MathMLや自己終了の `<math/>` は使えません。

### 数式で使える書き方 `T`

| 内容 | 記述例 |
| --- | --- |
| 上付き・下付き・まとまり | `x^{2}`・`a_{ij}`・`x_i^2`・`{a+b}` |
| 分数 | `\frac{a}{b}`・`\dfrac{a}{b}`・`\tfrac{a}{b}` |
| 根号 | `\sqrt{x}`・`\sqrt[3]{x}` |
| 二項係数 | `\binom{n}{r}` |
| 括弧 | `\left(\frac{a}{b}\right)`・`\left\{x\right\}` |
| 上の線・印 | `\bar{x}`・`\overline{x}`・`\hat{x}`・`\widehat{x}`・`\vec{x}`・`\dot{x}`・`\ddot{x}` |
| 和・積・積分・極限 | `\sum_{i=1}^{n}i`・`\prod_i x_i`・`\int_0^1 x\,dx`・`\oint f`・`\lim_{x\to 0}f(x)` |
| 添字の位置指定 | `\limits`・`\nolimits` |
| 文字のまとまり | `\text{説明}`・`\operatorname{rank}` |
| 数式内の空白 | `\,`・`\;`・`\:`・`\quad`・`\qquad`（簡略化した空白） |

`\!` は空白を追加しない指定です。`\displaystyle`・`\textstyle`、`\mathrm`・`\mathbf`・`\mathit`・`\mathsf`・`\mathtt`・`\mathbb`・`\mathcal`・`\textrm` は受け付けますが、TeX処理系と同じ書体・組版の再現を保証する指定ではありません。

行列・場合分け・式の整列では、列を `&`、行を `\\` で分けます。環境名は `matrix`・`pmatrix`・`bmatrix`・`Bmatrix`・`vmatrix`・`Vmatrix`・`cases`・`aligned`・`align` を使えます。

```text
$$
\begin{pmatrix}
a & b \\
c & d
\end{pmatrix}
$$
```

#### 数式の記号・関数名

以下は対応するコマンド名です。各名前の前に `\` を付け、大文字小文字を保ちます。例えば `\alpha`、`\Gamma`。

| 種類 | 名前 |
| --- | --- |
| ギリシャ小文字 | `alpha beta gamma delta epsilon zeta eta theta iota kappa lambda mu nu xi pi rho sigma tau upsilon phi chi psi omega` |
| ギリシャ大文字 | `Gamma Delta Theta Lambda Xi Pi Sigma Upsilon Phi Psi Omega` |
| 関数 | `sin cos tan log ln exp sinh cosh tanh lim limsup liminf` |
| 演算 | `cdot times div pm sum prod int oint` |
| 関係 | `leq le geq ge neq approx equiv in ni notin subset subseteq supset supseteq` |
| 集合・論理 | `cap cup setminus forall exists` |
| 矢印 | `to rightarrow leftarrow leftrightarrow Rightarrow Leftarrow Leftrightarrow` |
| その他 | `infty partial nabla angle circ ldots cdots langle rangle mid` |

未知の数式コマンドは名前が文字として残ることがあります。パッケージ読込、マクロ定義、TeX文書全体のコンパイルには対応しません。保存・出力後も必要な数式の表示を確認してください。

### 入力アシストの詳しい動作

| 操作 | ノートへ入る内容 |
| --- | --- |
| 入力欄に文字を入れ「適用」またはEnter | 選んだ書式を付けて挿入。ノートで文字を選択している場合は、その選択の直後へ挿入 |
| 入力欄を空にし、ノートで文字を選択して「適用」 | 選択した文字へ書式を適用 |
| 入力欄と選択がどちらも空で「適用」 | 案内を表示。ノートは変わらない |
| 「箇条書き」「引用」 | 入力欄、または選択した各行に `- `・`> ` を付ける。どちらも空なら書き始めの記号を挿入 |
| 「ページ参照」 | 表示中のPDFの名前とページ番号を文字として挿入 |
| 「PDFリンク」 | PDFの位置とノートを結ぶリンクの作成を開始 |

見出しは1〜6を選びます。太字・斜体・取消・下線・文字色・背景色を組み合わせられます。`d` は字下げ、`m` は行高の追加量、`s` は文字サイズです。単位と例は「独自装飾をまとめて書く」の表を参照してください。不要な数値欄は空にしてください。

入力した空白は保持し、末尾改行は自動追加しません。見出し・箇条書き・引用では、前後の文章から分けるために必要な改行を加えます。IME変換中のEnterは変換確定に使い、確定後に適用します。挿入できたときだけ入力欄を空にし、失敗時は文字を保持します。変更はノートの「元に戻す／やり直す」で戻せます。

### 使う形式と表示

`.clro`・`.md`・`.markdown` は同じMarkdown系の記述を扱います。`.txt`・`.csv` は装飾を解釈しないテキストです。`.tex` はTeXの数式区切りを扱う別の形式で、Markdownや独自装飾を使うノートには `.clro` などを選びます。

構成表示では書式を表示し、編集中の行や選択中の部分は編集用の原文になります。表とブロック数式は、それぞれ全体が編集単位です。書式記号を常に確認したいときは原文表示を使います。数式の表示には数式付きの表示モードを選びます。閲覧専用ビューアでの文書表示と、編集ソフトのノート表示には違いがあります。

### 記法を文字として残す・対応範囲

Markdownの記号は `\` でエスケープするか、行内コード・コードフェンスに入れます。コード内は `$`・`<math>`・独自装飾・`:::` もそのまま表示します。文字参照には `&amp;`・`&#169;`・`&#xA9;` のような名前・十進数・十六進数の形もあります。

生HTML、CSS、JavaScriptを実行・表示する機能はありません。HTMLコメントやYAML front matterを、非表示の管理情報として使う機能もありません。Mermaidのコードは編集ソフトではコードとして扱います。Markdownのあらゆる拡張機能や、他ソフトと同じ表示を保証するものではありません。

形式の選び方は [ノート形式](CLRO_Note_Format.md)、画面・設定の全項目は [ヘルプ](Help_Reference.md)、ビューアの検索・原文表示は [読み取り専用ビューア](Read_Only_Viewer.md) を参照してください。

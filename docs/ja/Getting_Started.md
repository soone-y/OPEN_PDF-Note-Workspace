# はじめに

## 起動

配布フォルダの `pdf_note_workspace.exe` を起動します。閲覧だけの場合は `readonly_viewer.exe` を使えます。EXE、DLL、`pdf_workspace_setup.json` は同じ配布フォルダに置いたままにしてください。

## ワークスペース

初回確認には同梱の `sample_workspace` を使えます。初回起動では `01_講義サンプル/第01回_基本操作` が選ばれ、PDFと標準ノートが1件ずつ開くので、そのまま表示、編集、保存を試せます。第03回の Office 変換結果 PDF は通常版だけに含まれ、Lite版には含まれません。自分の作業を始めるときは、書き込み可能なローカルフォルダを新しいワークスペースとして開いてください。配布フォルダとは別の場所にすると、更新時も作業データを守れます。

PDF、ノート、注釈の原本は直接上書きしません。通常の保存に加え、stage とバックアップを使って復旧できる状態を保ちます。

## 通常版と Lite版

通常版はローカルの LibreOffice runtime を使った Office-to-PDF 変換を含みます。Lite版は変換runtimeを含みませんが、PDF閲覧、注釈、ノート、保存・復元は同じです。

## 困ったとき

配布物の `docs/README.md`、`docs/legal/`、`licenses/` を確認してください。個人の作業データを配布フォルダへ置いている場合は、更新や削除の前にワークスペース全体を別の場所へコピーしてください。

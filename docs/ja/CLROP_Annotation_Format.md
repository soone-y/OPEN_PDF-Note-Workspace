# PDF注釈データを保存・移動・共有する

同梱リポジトリ版: (ZIP配布物ではここにバージョンが記載されます)

`.clrop` は、PDFへ重ねたマーカー・手書き・文字・数式・図形・ノートリンクをアプリが保存する注釈ファイルです。PDF本体とは別に記録し、PDF原本は変更しません。人が文章を書くノートは `.clro` です。

## PDF と 1 組で扱う

PDFと同じフォルダーに、拡張子だけが異なる同名のファイルを保存します。

```text
授業資料.pdf     元のPDF
授業資料.clrop   このPDFの注釈データ
```

PDFを開くと対応する注釈を重ねて表示します。再表示・編集には両方が必要です。PDFをコピー・移動・共有するときは `.clrop` も一緒に扱ってください。アプリ内の改名・移動は関連ファイルを追従させます。エクスプローラーで行う場合は、先にアプリで表示を閉じ、PDFと注釈の同名関係を保ちます。

## 保存しているもの

文字・数式の原文、線やマーカーの範囲、図形の形・色・太さ・透明度、位置・向きなどを保存します。PDFとの対応を確認する情報も含むため、別のPDFに同じ注釈を付ける目的でファイル名だけを変えないでください。

作成・再編集・消去の手順は[注釈ツールと色](Help_Reference.md#注釈ツールと色)を参照してください。変更は編集中に保護され、Ctrl+S・通常終了・出力前に `.clrop` へ保存します。ファイルや回次の切替だけでは原本へ保存しません。共有前にはCtrl+Sで保存を完了してください。[保存と復元](Save_and_Recovery.md)に失敗時の対応をまとめています。

## 受け取る人に合わせて共有する

| 相手の用途 | 渡すもの・結果 |
| --- | --- |
| 本ソフトで続けて編集する | PDFと同名の `.clrop`。ノートリンクを使う場合は参照先ノートも対応を保って渡す |
| 閲覧専用ソフトで読む | 保存済みのPDFと `.clrop` を同じフォルダーへ置く。[ビューア](Read_Only_Viewer.md)でPDF側を開く |
| 他のPDFソフトで読む | メインソフトの[PDF出力](Help_Reference.md#出力)で注釈を含む新しいPDFを作る。ノートへの移動リンクは引き継がない |

対応する新しい版で編集してください。古い版は新しい形式や図形・回転の情報を読めず停止する場合があります。注釈の表示方式はアプリ内表示とPDF/PNG出力で異なるため、渡すファイル自体を開いて確認します。

## 利用者が編集しない理由

中身はUTF-8のJSONですが、位置・図形・PDFとの対応を一貫させる必要があります。手作業での編集や拡張子変更は表示不良・誤対応の原因になります。追加・変更・削除はアプリで行ってください。`.clrop` を `.clro` に改名してノートとして編集しないでください。

保存に失敗した場合は、原本と保護データを残して[保存状態の確認と復旧](Save_and_Recovery.md#保存に失敗したとき)へ進みます。問題の確認前に注釈や管理フォルダーを削除しないでください。

## 形式を調べる技術者向け

JSONの構造、数値と改行、省略値、互換性、マーカー表示方式、弧・境界線・図形回転と座標の説明は、公開の[データ構造](https://soone-y.github.io/OPEN_PDF-Note-Workspace/introduction/core/data_schemas.html#1-注釈保存ファイル-clrop---classroom-pdf-annotation)へ集約しています。通常の操作には項目名や版番号の理解は必要ありません。

ノートとの比較は[ファイル形式](File_Formats.md)、文章の記法は[CLROノート形式](CLRO_Note_Format.md)を参照してください。

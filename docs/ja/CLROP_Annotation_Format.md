# `.clrop` PDF注釈データ

同梱リポジトリ版: (ZIP配布物ではここにバージョンが記載されます)

`.clrop` は、PDF Note WorkspaceがPDFへの注釈を保存するJSONファイルです。名前は、Classroom に由来するノート拡張子 `.clro` の PDF 注釈版を表します。ノートでもPDF本体でもなく、PDF本体も直接書き換えません。

## PDF と 1 組で扱う

PDFに注釈を付けると、アプリはPDFと同じフォルダに同じ名前の `.clrop` を置きます。

```text
授業資料.pdf     元のPDF
授業資料.clrop   授業資料.pdf に付けた注釈データ
```

PDFを開くと、アプリは対応する `.clrop` を読み込み、注釈をPDFの上に表示します。再表示・編集には両方が必要です。PDFを移動、改名、コピー、共有するときは、対応する `.clrop` も一緒に扱ってください。

## 保存しているもの

`.clrop` は現在 version 1 のJSONです。概念的には、PDFを確認するための情報と、ページごとの注釈の集合を持ちます。

```json
{
  "version": 1,
  "pdf_id": {
    "path": "授業資料.pdf",
    "size": 123456,
    "page_count": 12,
    "sha256": "..."
  },
  "pages": [
    { "page": 0, "items": [ { "type": "text" } ] }
  ]
}
```

これは構造を説明するための簡略例です。注釈の種類ごとに、位置、線、色、文字、数式、リンク先、図形など、必要な項目が変わります。

アプリが保存する注釈には、テキスト、数式、文字上のマーカー・色変更、自由線マーカー、手書き、直線、矢印、波線、ノートリンク用のマーカー、図形があります。`pdf_id` にはパスだけでなく、ファイルサイズ、ページ数、ページサイズ、SHA-256 など、対応するPDFを確認するための情報が入ります。

## 利用者が編集しない理由

JSONであっても、`.clrop` は手作業で書くための形式ではありません。項目の組合せやPDFとの対応が正しくなければ、注釈を表示できない、または別のPDFへの注釈として扱われるおそれがあります。

注釈の追加・修正・削除はアプリで行ってください。保存時はアプリがUTF-8 JSONを安全な書込みで更新します。保存に失敗した場合、保存済みの `.clrop` を途中まで書き換えず、未統合の変更は保存状態の確認や復元・バックアップで扱えます。

`.clrop` を `.clro` に改名してノートとして開く、拡張子だけを変えて種類を変える、テキストエディターで内容を修正することは行わないでください。

## `.clro` との違い

`.clro` は人が書くUTF-8ノートです。`.clrop` はPDFに重ねる注釈のアプリ管理データです。ノートの書き方や他ソフトとの扱いは [`.clro` ノート形式](CLRO_Note_Format.md) を参照してください。

形式全体の選び方と移動時の注意は [File_Formats.md](File_Formats.md) を参照してください。

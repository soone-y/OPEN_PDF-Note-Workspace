# PDF注釈データを保存・移動・共有する

同梱リポジトリ版: (ZIP配布物ではここにバージョンが記載されます)

`.clrop` は、PDFへ重ねたマーカー・手書き・文字・数式・図形・ノートリンクをアプリが保存する注釈ファイルです。PDF本体とは別に記録し、PDF原本は変更しません。人が文章を書くノートは `.clro` です。

## PDF と 1 組で扱う

PDFと同じフォルダーに、拡張子だけが異なる同名のファイルを保存します。

```text
授業資料.pdf     元のPDF
授業資料.clrop   このPDFの注釈データ
```

PDFを開くと対応する注釈を重ねて表示します。再表示・編集には両方が必要です。PDFをコピー・移動・共有するときは `.clrop` も一緒に扱ってください。アプリ内の改名・移動は関連ファイルを追従させます。エクスプローラーで行う場合は、先にアプリで表示を閉じ、PDFと注釈の同名関係を保ちます。

## 利用中のPDFと対応確認

メインソフトと閲覧専用ソフトは、開いているPDFへの外部ソフトからの書き込み・削除・改名・置換を防止します。外部ソフトで編集するときは、先に本ソフトのPDF表示をすべて閉じてください。別のソフトが書き込み用に開いているPDFは、その操作を終えてから開き直してください。通常の読み取りは引き続き可能です。

同名の `.clrop` を候補として探し、ファイルサイズ・ページ数・各ページの元の寸法を比較します。メインソフトでは不一致時に読込方法を選び、既存注釈の最初の一時保存前にはSHA-256も照合します。閲覧専用ソフトは、SHA-256が記録されている場合は内容も照合し、不一致の注釈を非表示にして通知します。SHA-256のない旧データは、取得できるサイズとページ情報で照合します。閲覧専用ソフトは対応情報を書き換えません。

PDFだけを外部で改名すると、通常のPDF読込では元の名前の `.clrop` は自動発見されません。両方の同名関係を保ってください。名前が異なる候補を探すには、次の対応調査を明示的に開始します。

## 対応するPDFを探す

`ツール → PDFとCLROPの対応調査` から、次の調査を別々に開始できます。

- **ディレクトリ内の突き合わせ**: 指定フォルダー直下のPDFとCLROPを調べます。同名PDFの有無も示し、改名後に残ったCLROPを確認できます。
- **CLROPからPDFを探す**: 調査するCLROPを選び、PDFを探すフォルダーを別に指定します。そのフォルダーにある他のCLROPは調査対象にしません。

「調査を開始」で候補を一覧にします。SHA-256一致、ページ構成とサイズの一致、ページ構成の一致、サイズ・ページ数・名前の一致という段階に分け、各根拠を列で表示します。ページ構成はページ数とページ順の寸法です。サイズが変わったPDFも構成が合えば候補に残ります。同じ内容のコピーが複数あれば、それぞれを表示します。

SHA-256は記録があり、バイト数が合う候補などに絞って計算します。「未確認」と「相違」は別の状態です。読取不能や不正データ、件数・時間・読込量の上限、中止では未確認の範囲を残します。サブフォルダーやCLROPに記録された別の場所へ探索範囲を自動拡張しません。

候補を選び「候補を読み取り専用でプレビュー」を押すと、別ウィンドウでPDFと注釈を一時表示します。不一致の候補も見比べられるよう、対応未確定の表示を常に付けます。配置・ページ対応は目視で確認してください。一致やプレビューは対応の適用ではなく、PDF・CLROPの改名、移動、ID更新は行いません。プレビューは通常の閲覧設定にも保存しません。

## 表示先のページを直す

注釈一覧には、現在のPDFに存在しないページの注釈も `P9 ［範囲外］` のように残ります。PDFとの対応を確認して読み込んだ後、一覧の注釈を右クリックし、プロパティを編集して「ページ」を変更できます。画面の番号は1始まりで、新しい移動先は現在のPDFに存在するページを指定します。

「適用」で注釈の所属ページを変更し、Undo/Redoで元に戻せます。ID・本文・スタイルとPDF上の座標は保持します。ページ寸法が異なる場合は、同じプロパティの座標も調整してください。現在の範囲外番号を変更しなければ、その注釈を保持したまま他のプロパティを編集できます。範囲外注釈を自動削除したり、ページの増減に合わせて自動移動したりはしません。

ページを変更した後は、注釈の配置を確認し、通常の保存操作で `.clrop` に反映してください。

## 保存しているもの

文字・数式の原文、線やマーカーの範囲、図形の形・色・太さ・透明度、位置・向きなどを保存します。PDFとの対応を確認する情報も含むため、別のPDFに同じ注釈を付ける目的でファイル名だけを変えないでください。

作成・再編集・消去の手順は[注釈ツールと色](Help_Reference.md#注釈ツールと色)を参照してください。変更は編集中に保護され、Ctrl+S・通常終了・出力前に `.clrop` へ保存します。ファイルや回次の切替だけでは原本へ保存しません。共有前にはCtrl+Sで保存を完了してください。[保存と復元](Save_and_Recovery.md)に失敗時の対応をまとめています。

## 受け取る人に合わせて共有する

| 相手の用途 | 渡すもの・結果 |
| --- | --- |
| 本ソフトで続けて編集する | PDFと同名の `.clrop`。ノートリンクを使う場合は参照先ノートも対応を保って渡す |
| 閲覧専用ソフトで読む | 保存済みのPDFと `.clrop` を同じフォルダーへ置く。[ビューア](Read_Only_Viewer.md)でPDF側を開く |
| 他のPDFソフトで読む | メインソフトの[PDF出力](Help_Reference.md#出力)で注釈を含む新しいPDFを作る。ノートへの移動リンクは引き継がない |

対応する新しい版で編集してください。古い版は新しい形式や図形・回転の情報を読めず停止する場合があります。注釈の表示方式はアプリ内表示とPDF/PNG出力で異なるため、渡すファイル自体を開いて確認します。

## 利用者が編集しない理由

中身はUTF-8のJSONですが、位置・図形・PDFとの対応を一貫させる必要があります。手作業での編集や拡張子変更は表示不良・誤対応の原因になります。追加・変更・削除はアプリで行ってください。`.clrop` を `.clro` に改名してノートとして編集しないでください。

保存に失敗した場合は、原本と保護データを残して[保存状態の確認と復旧](Save_and_Recovery.md#保存に失敗したとき)へ進みます。問題の確認前に注釈や管理フォルダーを削除しないでください。

## 形式を調べる技術者向け

JSONの構造、数値と改行、省略値、互換性、マーカー表示方式、弧・境界線・図形回転と座標の説明は、公開の[データ構造](https://soone-y.github.io/OPEN_PDF-Note-Workspace/introduction/core/data_schemas.html#1-注釈保存ファイル-clrop---classroom-pdf-annotation)へ集約しています。通常の操作には項目名や版番号の理解は必要ありません。

ノートとの比較は[ファイル形式](File_Formats.md)、文章の記法は[CLROノート形式](CLRO_Note_Format.md)を参照してください。

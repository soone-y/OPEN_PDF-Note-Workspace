# ヘルプ早見表

## このアプリについて

PDF、ノート、注釈をローカルで扱うアプリです。外部通信は行いません。編集中はPDF原本を直接書き換えず、復旧可能な作業データを使用します。

## 基本の流れ

1. 書き込み可能な場所のワークスペースを選びます。
2. PDFまたはノートを開き、編集します。
3. 区切りのよいタイミングで保存して統合します。

## 保存と復元

変更はまずstageに保持され、統合保存で原本へ反映されます。統合前にはバックアップが作られます。保存中に問題が起きた場合は、PDF、ノート、`__resource__` を変更せず、[保存と復元](Save_and_Recovery.md) と [問題が起きたとき](Troubleshooting.md) を確認してください。

## ノートと注釈

- `.clro` と `.md` はノート用のテキスト形式です。
- `.txt` は装飾を使わないプレーンテキストです。
- `.clrop` はPDFに対応する注釈データです。手作業で編集や改名をしません。

詳しくは [ファイル形式](File_Formats.md) を参照してください。

## 通常版・Lite版

通常版は同梱機能によるOfficeファイルのローカルPDF変換を利用できます。Lite版には変換runtimeを含みません。どちらもMicrosoft Officeやオンライン変換サービスを使用しません。

## 読み取り専用ビューア

`readonly_viewer.exe` はPDFと同梱文書を確認する閲覧用アプリです。編集は `pdf_note_workspace.exe` で行います。

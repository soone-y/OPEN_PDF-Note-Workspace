# 保存と復元

編集内容は、直ちに原本へ書き込まず、まずstageへ保護します。`Ctrl+S` または保存メニューで統合するときは、バックアップを作成し、安全な書込みが完了してから原本へ反映します。

## 使い分け

- 編集を続ける: 自動stage保護が途中状態を保持します。
- 区切りよく確定する: `Ctrl+S` で統合します。
- 未統合の変更を確認する: 「操作」または「保存」の「差分管理...」を開きます。
- 保存済みの以前の状態へ戻す: 「保存 > 復元/バックアップ...」を開きます。

## 注意

復元前に未統合の変更がないか確認してください。直前の編集を取り消すにはundo/redo、保存済みの状態へ戻すには復元/バックアップを使います。問題を確認する前に `__resource__` を削除・移動しないでください。

大きな編集や外部共有の前には、`Ctrl+S` で統合してからワークスペース全体をコピーしてください。

# ファイル形式

| 拡張子 | 用途 |
| --- | --- |
| `.clro` | 本ソフトの標準ノート。UTF-8テキストです。 |
| `.md` / `.markdown` | Markdown互換ノート。既存ファイルを自動改名しません。 |
| `.tex` | TeX数式を含むノート。 |
| `.txt` / `.csv` | 書式なしノート。`.csv` を表計算として処理しません。 |
| `.clrop` | PDFに対応する注釈データ。ノートではありません。 |

PDFへ注釈を付けると、PDFと同じフォルダへ同名の `.clrop` が作られます。注釈を再表示・編集するにはPDFと `.clrop` の両方が必要です。PDFを移動・共有するときは対応する `.clrop` も一緒に扱い、手動編集や拡張子変更はしないでください。

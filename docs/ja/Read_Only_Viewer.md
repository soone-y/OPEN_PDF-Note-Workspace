# 読み取り専用ビューアで複数の資料を読む

`readonly_viewer.exe` は、PDFと `.clrop` の注釈、ノート、同梱文書を複数のタブで閲覧する小規模なWindowsアプリです。編集用のメインソフトを起動せずに、資料を読み比べられます。

## 作った理由

PDF Note Workspaceの環境でも、複数のファイルを開いたまま行き来して読みたい。そのために、PDFと別保存した `.clrop` の注釈も表示できる、閲覧に用途を絞ったアプリを用意しました。表示にはWindowsの部品とPDFiumを使い、ブラウザエンジンやオンラインサービスは使いません。

ビューアの画面は固有の固定色を使い、メインソフトのテーマ設定には連動しません。

## PDFと注釈を開く

通常版・Lite版の配布フォルダーにある `readonly_viewer.exe` を起動し、`ファイルを開く`（`Ctrl+O`）でPDFを選びます。メインソフトの閲覧専用ソフトの項目からも開けます。

同じフォルダーに同じ名前の `.clrop` があれば、保存された注釈をPDFへ重ねて表示します。

文字注釈は、保存されたフォント・ポイントサイズ・改行・縦書き・内容の向きを使って表示します。星図形の「線（五芒星）」「枠線」「塗りつぶし」と図形全体の回転にも対応し、PDF本来の向きや閲覧中の表示回転と組み合わせて表示します。

```text
授業資料.pdf     元のPDF
授業資料.clrop   このPDFの注釈データ
```

コピー・移動・共有するときは、この2ファイルを一緒に扱ってください。注釈を閲覧するには、メインソフトで注釈を保存しておきます。`.clrop` だけを開くと、注釈の種類やページごとの情報を文書として確認できます。PDFのページを見るときはPDF側を開いてください。

## 複数のファイルを読み比べる

- `ファイルを開く` で複数選択するか、ファイル一覧から追加して、タブで切り替えます。`Ctrl+Tab` は次のタブ、`Ctrl+Shift+Tab` は前のタブへ移動します。
- 左側でファイルと目次を選び、右側で本文を読みます。フォルダーを開き、戻る・上のフォルダーへ移動することもできます。
- フォルダーの移動は一覧の上にある「← 戻る」「↑ 上へ」で操作します。親フォルダーはファイル一覧に混ぜません。移動先のフォルダーには「›」、ファイルにはPDF・ノート・注釈データなどの種別を添えます。
- ウィンドウの幅は最小480px（表示倍率100%時）まで縮められます。狭い幅では左の一覧が一時的に隠れ、広げると戻ります。上部に収まらない表示切替は「表示」メニューから操作できます。
- 狭い幅で左の一覧が隠れているときは、上部の「資料一覧」から資料を選べます。「ファイル」メニューにも同じ項目があり、集中表示中も利用できます。一覧は選択・取消後に閉じ、ウィンドウの幅は変えません。
- 開いたフォルダーに `pdf/`・`note/` がある場合は、それぞれ「PDF資料 (pdf)」「ノート (note)」に分けて中身を表示します。片方だけでも対応し、区分は折りたためます。それ以外のフォルダーと直置きファイルも表示し、区分内のサブフォルダーを選ぶとその中へ移動できます。
- タブをドラッグして並べ替えます。別のビューアウィンドウへ移動したり、ウィンドウの外へドラッグして分離したりすると、資料を並べて読めます。タブの右クリックメニューからも移動できます。
- `Ctrl+F` で本文やPDFの文字を検索します。`F3` で次、`Shift+F3` で前の結果へ進みます。
- 「表示」→「集中表示」（`Ctrl+B`）で、メニューバーの下全体を閲覧に使います。タブ切替は「タブ一覧」、倍率や表示方式の変更は「表示」から操作できます。検索欄は検索時に開き、検索の実行または `Esc` で閉じます。通常表示に戻すには、もう一度「集中表示」または `Ctrl+B` を使います。

本文右側の細い帯は、通常は日本語を含む行を示します。検索語の入力中は、表示中の本文で検索に一致した行にだけ印を表示します。検索語を消すと通常の表示へ戻ります。帯をクリックすると、その付近へ移動できます。

## 長いファイルの読込位置を指定する

50 MiBを超えるテキスト、またはバイナリと判定された64 KiBを超えるファイルは、全体を読み込む前に範囲を選びます。既定の読込量は64 KiBです。

- 開始位置は先頭を0としたバイト位置、読込量はバイト数です。10進数または `0x` 付き16進数で入力します。終了位置は含みません。
- 開始スライダーは読込量を保って位置を移動します。終了スライダーで範囲を広げられます。「前の範囲」「次の範囲」は現在の読込量ずつ移動します。入力中は選択範囲と負荷表示だけを更新し、「この範囲を開く」で読み込みます。
- 開いた後は「読込範囲」、表示メニュー、またはタブの右クリックから指定し直せます。画面が狭くボタンが隠れているときはメニューを使います。通常サイズのテキストやバイナリにも指定できます。

1回の上限は256 MiBで、利用可能なメモリに対して負荷の推定が大きすぎる範囲は確定できません。入力不正・取消・読込失敗では現在の表示を保持します。原本への書き込みは行いません。範囲は閲覧中のタブで管理し、次回起動には保存しません。

「16進数」は1バイトを2桁の16進数で、「バイナリ」は8桁の2進数（0・1）で表示します。左端は元ファイル上の位置を16進数で示し、右端には表示可能なASCII文字を並べます。それ以外の値は `.` で表し、日本語などの文字コードの復号は行いません。1行は16進数表示では16バイト、バイナリ表示では8バイトです。同じウィンドウ内のタブ切替では表示方式を保持し、範囲を変えても維持します。切替で原本や読込範囲を変更することはありません。

どちらも一度に表示するのは読込範囲の先頭64 KiBまでで、省略がある場合は案内を表示します。続きを見るには読込範囲を変更します。原文表示でテキストを文字の途中で区切ると文字化けする場合があります。バイト単位の確認には16進数表示またはバイナリ表示を使ってください。

## PDFと注釈の対応を確認する

PDFは閲覧中の外部編集・削除・改名・置換を防ぐために保護します。外部ソフトで編集する前にPDFの表示を閉じてください。同名の `.clrop` はサイズ・ページ数・元のページ寸法で照合し、SHA-256が記録されている場合は内容も確認します。不一致なら注釈を非表示にし、PDF表示欄へ通知します。対応の確認やID更新はメインソフトで行ってください。`.clrop` が修正された場合は再照合します。原本や対応情報を閲覧専用ソフトで書き換えることはありません。

メインソフトの `ツール → PDFとCLROPの対応調査` からは、候補だけを表示する専用プレビューも開けます。これは対応未確定の読み取り専用表示で、通常のペア照合による採用とは別です。不一致の注釈も一時的に重ねて配置を確認でき、設定や対応情報は保存しません。[候補の探し方](CLROP_Annotation_Format.md#対応するpdfを探す)で2種類の調査方法を説明しています。

## PDFの範囲と文字を選択する

PDFをドラッグして枠で対象範囲を囲みます。次にその枠内をドラッグすると、文字を選択して `Ctrl+C` でコピーできます。枠を越えてドラッグしても枠外の文字は混ざりません。文字を選択していないときは、従来どおり枠内の全文をコピーします。

`Esc` は文字選択を解除し、もう一度押すと枠を解除します。別の範囲を囲み直すときは枠外からドラッグします。選択は閲覧中だけの状態で、PDFや注釈への書き込みは行いません。

PDF表示中は `表示` → `白黒表示` でグレースケールに切り替えられます。もう一度選ぶとカラー表示に戻ります。この表示設定はビューアを終了すると解除され、PDFや設定ファイルには保存されません。

PDF表示中は `表示` メニューの左右90度回転を選ぶと、そのタブの全ページを一時的に回転できます。右回転は `Ctrl+R`、左回転は `Ctrl+Shift+R` です。`表示回転を解除（このタブ）` でPDF本来の向きに戻ります。角度はタブの切り替えや別ウィンドウへの移動でも保持し、ビューアを終了すると解除します。PDFや `.clrop`、設定ファイルには保存しません。

## ノートや文書も読む

Markdown、`.clro` ノート、プレーンテキスト、バイト表示にも対応します。読書表示では見出し・表と、対応するMermaid図を文書内に表示します。原文を確認したいときは表示を切り替えます。

| キー | 表示 |
| --- | --- |
| `Ctrl+1` | 読書表示 |
| `Ctrl+2` | 原文 |
| `Ctrl+3` | バイト |
| `Ctrl+4` | 図の一覧 |

表示の種類はファイルに応じて使えます。対応しない図の構文は原文で確認できます。拡大・縮小は表示上のボタン、`Ctrl++` / `Ctrl+-`、標準倍率への復帰は `Ctrl+0` です。

文書内の図を右クリックすると、その図を別ウィンドウで開きます。初期表示は全体を収め、拡大・縮小・等倍・`全体表示` のボタンと、縦横のスクロールバーで確認できます。図の一覧では上の倍率ボタンも図へ作用します。文書内の図にマウスを置いても、通常のホイール操作で本文をスクロールできます。

本文・PDF・図の位置は、開いているタブの中で一時的に保持します。表示モードを切り替えてもそれぞれの位置へ戻り、本文の幅を変えたときは画面上端の文字を目印に位置を調整します。スクロール位置を設定ファイルへ保存して、終了後に復元する機能ではありません。

## 共通操作のキー

「設定 → ショートカット一覧」で、このビューアのキーを参照できます。

| キー | 操作 |
| --- | --- |
| `Ctrl+G` | ページ番号を指定して移動。表示中の範囲外のページも指定可能 |
| `Ctrl+E` | 現在のページ全体をPDF表示欄に収め、倍率と表示位置を整え直す |
| `Ctrl+O` / `Ctrl+Shift+O` | ファイル／フォルダーを開く |
| `Ctrl+Shift+Q` / `Ctrl+Alt+Shift+Q` | 現在のタブ／すべてのタブを閉じる |
| `Ctrl+Shift+A` | 注釈を表示／非表示 |
| `Ctrl+Shift+←` / `Ctrl+Shift+→` | このタブを左／右へ90度回転 |
| `Ctrl+Shift+0` | このタブの表示回転を解除 |
| `Ctrl+Alt+E` | 既存の注釈付きPDF出力を開く |

ページ移動・注釈表示・回転は、PDF表示中に検索入力欄以外で使います。入力欄の文字選択操作を優先します。出力は保存先の選択から進み、原本を変更しません。従来の `Ctrl+R`／`Ctrl+Shift+R` の回転キーも使用できます。メインソフトのワークスペースメモ・出力ダイアログ・簡易出力とは機能が異なります。

## 注釈付きPDFを別ファイルへ出力する

PDFと対応する `.clrop` を開き、「ファイル」の「注釈付きPDFを書き出し...」（Ctrl+Alt+E）で元PDFとは別の保存先を選びます。元PDFと同じパスには出力しません。原本のPDF・注釈・ノートは保存変更しません。

PDFのコピー権限がない場合は、本文を含む選択のコピーを停止します。注釈だけを選択した場合はコピーできます。暗号化や電子署名のあるPDFの書き出しは、保護を保持できないため停止します。制限で停止した場合は、PDF欄に理由を表示します。

ビューアの出力は注釈をページ内容へ描く方式です。メインソフトの標準PDF注釈としての出力とは異なり、出力した書き込みを個別注釈として再編集する用途には向きません。見た目を含め出力結果を確認し、標準注釈で渡す場合は[メインソフトの出力](Help_Reference.md#出力pdfでは書き込みをどう保存するか)を使います。編集を続けるための元PDFと `.clrop` は残してください。

## ファイルと設定の扱い

通常の閲覧操作では、元のPDF、`.clrop`、ノートを編集・保存しません。注釈やノートの編集はメインソフトを使ってください。

「次回の起動」で「次回起動時に資料を開き直す」をONにし、必要な資料やフォルダーだけを「この資料を次回も開く」「このフォルダーを次回も開く」で登録します。**ONでも登録0件を許します。** ONにしただけでは、表示中のPDF・ノートやフォルダーは登録されません。

「次回開く対象を確認・整理」で登録対象を確認でき、「対象から外す」を選ぶとその登録を解除します。タブを閉じても登録は残ります。開き直しをOFFにしても登録内容は保持し、次の起動では開きません。設定の変更はexeと同じ場所の `readonly_setup.json` に保存し、保存できなければ変更前の設定へ戻します。既存の専用設定を優先し、登録0件を古い共有設定の対象で補うことはありません。

exeだけを移動せず、同梱DLL、`LICENSE.md`、`licenses/` も一緒に保管してください。`ライセンス` メニューで案内と原文を確認できます。形式の詳細は [PDFとCLROPの関係](CLROP_Annotation_Format.md)、編集と出力は [アプリの使い方](Using_the_App.md) を参照してください。

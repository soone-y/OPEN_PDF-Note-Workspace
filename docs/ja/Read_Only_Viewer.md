# 読み取り専用ビューアで複数の資料を読む

`readonly_viewer.exe` は、PDFと `.clrop` の注釈、ノート、同梱文書を複数のタブで閲覧する小規模なWindowsアプリです。編集用のメインソフトを起動せずに、資料を読み比べられます。

## 作った理由

PDF Note Workspaceの環境でも、複数のファイルを開いたまま行き来して読みたい。そのために、PDFと別保存した `.clrop` の注釈も表示できる、閲覧に用途を絞ったアプリを用意しました。表示にはWindowsの部品とPDFiumを使い、ブラウザエンジンやオンラインサービスは使いません。

ビューアの画面は固有の固定色を使い、メインソフトのテーマ設定には連動しません。

## PDFと注釈を開く

通常版・Lite版の配布フォルダーにある `readonly_viewer.exe` を起動し、`ファイルを開く`（`Ctrl+O`）でPDFを選びます。メインソフトの閲覧専用ソフトの項目からも開けます。

同じフォルダーに同じ名前の `.clrop` があれば、保存された注釈をPDFへ重ねて表示します。

```text
授業資料.pdf     元のPDF
授業資料.clrop   このPDFの注釈データ
```

コピー・移動・共有するときは、この2ファイルを一緒に扱ってください。注釈を閲覧するには、メインソフトで注釈を保存しておきます。`.clrop` だけを開くと、注釈の種類やページごとの情報を文書として確認できます。PDFのページを見るときはPDF側を開いてください。

## 複数のファイルを読み比べる

- `ファイルを開く` で複数選択するか、ファイル一覧から追加して、タブで切り替えます。`Ctrl+Tab` は次のタブ、`Ctrl+Shift+Tab` は前のタブへ移動します。
- 左側でファイルと目次を選び、右側で本文を読みます。フォルダーを開き、戻る・上のフォルダーへ移動することもできます。
- タブをドラッグして並べ替えます。別のビューアウィンドウへ移動したり、ウィンドウの外へドラッグして分離したりすると、資料を並べて読めます。タブの右クリックメニューからも移動できます。
- `Ctrl+F` で本文やPDFの文字を検索します。`F3` で次、`Shift+F3` で前の結果へ進みます。`Ctrl+B` で左側の一覧を隠し、本文へ集中できます。

本文右側の細い帯は、通常は日本語を含む行を示します。検索語の入力中は、表示中の本文で検索に一致した行にだけ印を表示します。検索語を消すと通常の表示へ戻ります。帯をクリックすると、その付近へ移動できます。

## PDFの範囲と文字を選択する

PDFをドラッグして枠で対象範囲を囲みます。次にその枠内をドラッグすると、文字を選択して `Ctrl+C` でコピーできます。枠を越えてドラッグしても枠外の文字は混ざりません。文字を選択していないときは、従来どおり枠内の全文をコピーします。

`Esc` は文字選択を解除し、もう一度押すと枠を解除します。別の範囲を囲み直すときは枠外からドラッグします。選択は閲覧中だけの状態で、PDFや注釈への書き込みは行いません。

PDF表示中は `表示` → `白黒表示` でグレースケールに切り替えられます。もう一度選ぶとカラー表示に戻ります。この表示設定はビューアを終了すると解除され、PDFや設定ファイルには保存されません。

PDF表示中は `表示` メニューの左右90度回転を選ぶと、そのタブの全ページを一時的に回転できます。右回転は `Ctrl+R`、左回転は `Ctrl+Shift+R` です。`表示回転を解除（このタブ）` でPDF本来の向きに戻ります。角度はタブの切り替えや別ウィンドウへの移動でも保持し、ビューアを終了すると解除します。PDFや `.clrop`、設定ファイルには保存しません。

## ノートや文書も読む

Markdown、`.clro` ノート、プレーンテキスト、バイト表示にも対応します。読書表示では見出し・表と、対応するMermaid図を文書内に表示します。原文を確認したいときは表示を切り替えます。

| キー | 表示 |
| --- | --- |
| `Ctrl+1` | 読書表示 |
| `Ctrl+2` | 原文 |
| `Ctrl+3` | バイト |
| `Ctrl+4` | 図の一覧 |

表示の種類はファイルに応じて使えます。対応しない図の構文は原文で確認できます。拡大・縮小は表示上のボタン、`Ctrl++` / `Ctrl+-`、標準倍率への復帰は `Ctrl+0` です。

文書内の図を右クリックすると、その図を別ウィンドウで開きます。初期表示は全体を収め、拡大・縮小・等倍・`全体表示` のボタンと、縦横のスクロールバーで確認できます。図の一覧では上の倍率ボタンも図へ作用します。文書内の図にマウスを置いても、通常のホイール操作で本文をスクロールできます。

本文・PDF・図の位置は、開いているタブの中で一時的に保持します。表示モードを切り替えてもそれぞれの位置へ戻り、本文の幅を変えたときは画面上端の文字を目印に位置を調整します。スクロール位置を設定ファイルへ保存して、終了後に復元する機能ではありません。

## 共通操作のキー

「設定 → ショートカット一覧」で、このビューアのキーを参照できます。

| キー | 操作 |
| --- | --- |
| `Ctrl+G` | ページ番号を指定して移動。表示中の範囲外のページも指定可能 |
| `Ctrl+E` | 現在のページ全体をPDF表示欄に収め、倍率と表示位置を整え直す |
| `Ctrl+O` / `Ctrl+Shift+O` | ファイル／フォルダーを開く |
| `Ctrl+Shift+Q` / `Ctrl+Alt+Shift+Q` | 現在のタブ／すべてのタブを閉じる |
| `Ctrl+Shift+A` | 注釈を表示／非表示 |
| `Ctrl+Shift+←` / `Ctrl+Shift+→` | このタブを左／右へ90度回転 |
| `Ctrl+Shift+0` | このタブの表示回転を解除 |
| `Ctrl+Alt+E` | 既存の注釈付きPDF出力を開く |

ページ移動・注釈表示・回転は、PDF表示中に検索入力欄以外で使います。入力欄の文字選択操作を優先します。出力は保存先の選択から進み、原本を変更しません。従来の `Ctrl+R`／`Ctrl+Shift+R` の回転キーも使用できます。メインソフトのワークスペースメモ・出力ダイアログ・簡易出力とは機能が異なります。

## ファイルと設定の扱い

通常の閲覧操作では、元のPDF、`.clrop`、ノートを編集・保存しません。次回も開きたい資料は、`設定` の復元を有効にして、`パス管理` でタブやフォルダーを永続化します。この復元設定はexeと同じ場所の `readonly_setup.json` に保存します。注釈やノートの編集、PDFと注釈を1つのPDFファイルにまとめる出力はメインソフトを使ってください。

exeだけを移動せず、同梱DLL、`LICENSE.md`、`licenses/` も一緒に保管してください。`ライセンス` メニューで案内と原文を確認できます。形式の詳細は [PDFとCLROPの関係](CLROP_Annotation_Format.md)、編集と出力は [アプリの使い方](Using_the_App.md) を参照してください。

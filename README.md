# PDF Note Workspace

Windows 向けの PDF 学習ワークスペースです。PDF 閲覧、非破壊注釈、ノート編集を一つのアプリで扱います。

This is a Windows PDF study workspace for viewing PDFs, making non-destructive annotations, and editing notes in one app.

![PDF Note Workspace の画面。PDF表示、注釈ツール、ノート編集を一つのウィンドウで扱う。 / PDF Note Workspace showing PDF viewing, annotation tools, and note editing in one window.](docs/images/app_overview.png)

## 入手方法 / Download

GitHub Releases の Assets から、利用する言語と edition に合う ZIP を取得してください。

Download the ZIP that matches your language and edition from GitHub Releases assets.

| 目的 / Need | ファイル名の目安 / Asset name pattern |
| --- | --- |
| 日本語・通常版 / Japanese Full | `pdf_note_workspace_<version>_ja_full.zip` |
| 日本語・軽量版 / Japanese Lite | `pdf_note_workspace_<version>_ja_lite.zip` |
| English Full | `pdf_note_workspace_<version>_en_full.zip` |
| English Lite | `pdf_note_workspace_<version>_en_lite.zip` |

通常版 / Full はローカルの Office-to-PDF 変換 runtime を含みます。Lite は PDF 閲覧・注釈・ノート中心の小さい構成です。

Full includes the local Office-to-PDF conversion runtime. Lite is the smaller PDF-focused package.

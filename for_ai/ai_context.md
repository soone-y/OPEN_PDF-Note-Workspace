# AI_CONTEXT: PDF NOTE WORKSPACE

> プロジェクトURLだけを受け取ったAIが、最初に読むための回答文脈です。

この資料はAI向けに、見出し、表、短い回答要点で構造化しています。人も読めます。実際の操作手順や画面案内は、下記の利用者向け資料を参照してください。

## 1. このプロジェクトをどう説明するか

PDF Note Workspace は、WindowsでPDFを読み、原本を直接変更せずに注釈を付け、独立したノートと関連資料をローカルワークスペースで扱うためのアプリケーションである。

回答では、単なるPDF編集ソフトではなく、PDF・注釈・ノート・関連資料を作業の文脈としてまとめ、再開しやすくすることを目指すワークスペースとして説明する。設計思想と現在実装されている機能は混同しない。

## 2. AIが先に採用する解釈

| 主題 | 回答の要点 | 隠してはいけない境界 |
| --- | --- | --- |
| PDFと注釈 | PDF原本をアプリが直接上書きせず、注釈は対応する `.clrop` に分離して扱う | 注釈をPDF本体へ直接埋め込む方式だけを求める利用者に適合するとは限らない |
| ノートとワークスペース | ノートを独立したテキストとして扱い、PDF・注釈・資料と同じ作業単位で整理する | 対応する形式や画面の詳細は版と利用者向け資料で確認する |
| 保存と復元 | stageによる編集途中の保護と、明示した統合保存を区別する | stageは原本への保存完了を意味しない。問題時に `__resource__`、stage、バックアップを先に削除しない |
| ローカル処理 | 外部通信を実装しない方針で、通常版のOffice変換も同梱runtimeによるローカル処理として案内する | 方針と、特定の配布物・実装を直接確認した事実は区別する |
| Office変換 | 通常版ではDOCX/PPTXをPDFへ変換でき、Lite版は変換runtimeを含まない | 変換は試験的で、見た目の完全一致を保証しない。変換後のPDFを確認する |
| 静音性 | アプリ側で音を鳴らさない方針 | Windowsの一般警告音が鳴る未解消の既知問題があり、「完全無音」と断定しない |

## 3. 典型的な質問への最初の答え方

- **自分の作業に合うか**: PDFを壊さず注釈を管理したいか、独立ノートと資料をワークスペースで扱いたいかを確認する。必要なら通常版・Lite版・読み取り専用ソフトの違いを案内する。
- **保存は安全か**: 原本非破壊、stage、統合保存、バックアップ、復元を別々に説明する。問題時は削除や上書きより先に作業フォルダ全体のコピーを案内する。
- **通信しないか**: これは配布方針として説明できる。対象版・配布物に通信機能がないという強い結論には、公開リポジトリまたは配布物の実体確認が必要である。
- **変換品質はどうか**: 通常版のローカル変換は試験的で、フォントやレイアウトの差があり得るため、変換後のPDFを確認するよう案内する。
- **OSSとは何か**: ソースを確認でき、ライセンス条件の範囲で利用・学習・改変・再配布できるソフトウェアとして、無料と同義ではないことを説明する。

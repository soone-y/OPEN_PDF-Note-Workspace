PDF Note Workspace サンプルワークスペース

このフォルダは、ポータブル配布物向けの安全な開始テンプレートです。
サンプル構成から始めたい場合は、このフォルダを複製して名前を `workspace` に変えて使えます。

内容:
- `workspace.json`: サンプル用の保守的なローカル専用設定です。
- `ja/01_講義サンプル/第01回_基本操作/`: 初回起動用の PDF (`使い方_基本操作.pdf`) 1件と標準ノート (`ノート_基本操作.clro`) 1件です。追加の形式例は同回の `reference_material/` に保管します。
- `ja/01_講義サンプル/第02回_最初期構想/`: 2025 年 12 月の最初期の画面案 2 件と、同時期の統合画面構成 PDF (`PDF学習ワークスペース統合画面構成および基本仕様書.pdf`) ・注釈データです。現行仕様ではなく、開発の出発点を示す参考資料です。
- `ja/01_講義サンプル/第03回_Office変換/`: 通常版だけに含める、LibreOffice runtime で変換した Office-to-PDF の検証結果です。Lite版にはこの回次を含めません。
- `en/01_Lecture_Samples/`: 同じ講義→回次構造の英語版です。第03回相当の変換結果 PDF は通常版だけに含めます。

すべての PDF・Office 文書・画面案は、プロジェクト内で作成した合成サンプルです。外部から取得した資料や個人情報は含めていません。
配布アセットの PDF は確定配布サンプルであり、今後の変換品質向上に伴って積極的には差し替えません。

PDF Note Workspace sample workspace

This folder is a safe starter template for a portable release.
You can copy this folder and rename the copy to "workspace" if you want to start with the sample structure.

Contents:
- `workspace.json`: conservative local-only settings for the sample.
- `ja/01_講義サンプル/第01回_基本操作/`: the first-launch pair: one basic usage guide PDF (`使い方_基本操作.pdf`) and one standard note (`ノート_基本操作.clro`). Additional note-format examples are kept in `reference_material/`.
- `ja/01_講義サンプル/第02回_最初期構想/`: two early UI mockups from December 2025, plus the contemporary integrated-screen design PDF (`PDF学習ワークスペース統合画面構成および基本仕様書.pdf`) and annotation data. They are historical reference material, not the current specification.
- `ja/01_講義サンプル/第03回_Office変換/`: two Office-to-PDF validation results for the Full edition only. Lite omits this session.
- `en/01_Lecture_Samples/`: an English course-to-session hierarchy with equivalent Session 01 through Session 03 examples. Its conversion-result PDFs are Full-edition-only.

All PDFs, Office documents, and UI mockups are synthetic samples created within this project. They contain no externally sourced material or personal information.
The bundled release sample PDFs are fixed sample documents and will not be routinely replaced with future conversion quality updates.

This is the sample workspace for the English PDF Note Workspace release.
Open this directory directly, or use the setup file included in the distribution.
On a first launch, Session 01 in `01_Lecture_Samples` is selected and opens one practice PDF with its companion note. See `Getting_Started.md` for startup and saving guidance.
The Full edition also includes Session 03 conversion-result PDFs. Lite deliberately omits that session.

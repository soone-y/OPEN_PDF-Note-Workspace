# English Sample Workspace

This is an empty sample workspace for safely checking the application. Copy this folder to another writable location before using it for your own work.

When you add PDFs, notes, or annotations, the application creates `__resource__` for recoverable saves and backups. Do not remove or move it manually.

The course-style examples are in `01_Lecture_Samples`, ordered from Session 01. On a first launch, Session 01 opens its one PDF and one companion note automatically. Lite does not distribute Session 03, which contains conversion-result PDFs.

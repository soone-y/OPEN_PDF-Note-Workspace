This is a historical reference exercise, not the current application specification or UI.

`early_design_reference.pdf` records the purpose and safe handling of an early-design PDF sample. You can open it, add an annotation, and export an annotated copy. The original PDF is never overwritten.

The Japanese edition contains the original historical design materials. This English edition provides a separately authored English reference so that its filenames and user-facing text remain English-only.

# Session 01: Basic Operation Sample This folder contains short examples for each note format. You can safely check note display, editing, and saving without adding a PDF. 1. Open `basic_operations.clro` and edit a heading or checklist item. 2. Open `math.md` and `plain_text.txt` to compare the formats. 3. Save your changes. Copy the entire workspace first if you want to keep its original state. If you add a PDF to try annotations, annotation data is stored separately from the original PDF. Do not remove or move `__resource__`; it is needed for recovery and backups. Open `basic_workflow_guide.pdf` for a small PDF annotation exercise.

Course-style sample folders. - `Session_01_Basics`: a PDF guide and note-format examples for viewing, annotation, editing, and saving. - `Session_02_Early_Design`: an English reference PDF for a historical early-design exercise. It is not the current specification. - `Session_03_Office_Conversion`: two English conversion-result reference PDFs, one for a presentation-style document and one for a word-processing-style document. The Full edition contains all three sessions. Lite omits Session 03 and its conversion-result PDFs. Keep PDFs, notes, and annotation data for one session in that same session folder.

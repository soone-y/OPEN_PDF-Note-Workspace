# Markdown ノート

Markdownは、見出しやリストを使って文章を構造化する形式です。`'single quotation'` は通常の文字で、コードの表示には **バッククォート** の `inline_code` を使います。

## 見出しと強調

**太字**、*斜体*、~~取り消し線~~、`const value = 42;`

> `>` で始まる行は引用です。重要な補足を本文から分けられます。

::: note char=#1a73e8 title="補足"
`:::` で囲むコンテナです。関連する補足をひとかたまりにできます。
:::

---

## リスト

1. 章を読む
2. 要点を書く
- 補足を追加する
- [x] 確認済み
- [ ] 復習する

## コードコンテナ

```text
title: 第02回
format: markdown
```

## 表と数式

| 記法 | 用途 | 例 |
| :--- | :---: | ---: |
| `#` | 見出し | `## 小見出し` |
| `-` | 箇条書き | `- 項目` |
| `` ` `` | インラインコード | `value` |

インライン数式: \(a^2 + b^2 = c^2\)

ブロック数式:

$$
\int_0^1 x^2\,dx = \frac{1}{3}
$$

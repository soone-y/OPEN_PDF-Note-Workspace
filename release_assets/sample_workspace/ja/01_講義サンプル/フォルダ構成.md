# フォルダ構成

このファイルは `01_講義サンプル` の直下にあるため、回次の一覧では「直下ファイル」として表示されます。

ワークスペースは「授業 → 回次」の二階層です。授業一覧で選ぶフォルダが授業、その中のフォルダが回次です。各回次のフォルダに置いたPDFとノートが、PDF一覧とノート一覧に並びます。授業フォルダの直下に置いたファイルは、このファイルのように「直下ファイル」から開けます。

```text
sample_workspace/
├─ 01_講義サンプル/                授業
│  ├─ フォルダ構成.md               このファイル（直下ファイル）
│  ├─ 第01回_基本操作/              回次
│  ├─ 第02回_ノート形式/            回次
│  ├─ 第03回_最初期構想/            回次
│  ├─ 第04回_Office変換/            回次（通常版のみ）
│  └─ 第05回_数式表示/              回次
├─ __pdf_note_workspace__/         アプリ管理用（資料を置かない）
└─ workspace.json                  ワークスペースの設定
```

## 各回次の内容

- `第01回_基本操作`: 初回起動時に開くPDFと標準ノートの組です。閲覧、注釈、編集、保存を試せます。
- `第02回_ノート形式`: Markdown、TeX原文、プレーンテキスト、CSV、標準ノートを形式ごとに直接開く教材です。標準ノートと `PDFリンク練習.pdf` は、ノートとPDFを往復するリンクの例です。
- `第03回_最初期構想`: 2025年12月の最初期の画面案と統合画面構成です。現行仕様ではありません。`.clro` ノートを含みます。
- `第04回_Office変換`: LibreOffice runtimeで変換した、ネイティブ図表を含むPowerPoint由来PDF 1件と `.clro` ノートです。
- `第05回_数式表示`: ノートでの数式の書き方と表示位置、右下領域の「MathBox入力」からPDFへ数式をドラッグして置く操作を試す `.clro` ノートと練習用PDFです。

通常版は第01回から第05回までを含みます。Lite版には変換runtimeと第04回は含まれません。

## 用語

- ワークスペース: 資料とノートをまとめて置く、利用者が選んだフォルダーです。この `sample_workspace` もワークスペースです。以前の版では「ルートフォルダ」と表示していました。
- 授業・回次: ワークスペースの中の2段の階層です。用語設定によって「上位項目・下位項目」と表示する場合があります。
- `__pdf_note_workspace__`: アプリが作業保護やバックアップを置く作業データのフォルダーです。

ほかの用語と詳しい意味は、同梱文書の詳細ヘルプ（`Help_Reference.md`）の「用語」にまとめています。

## 自分の資料を置くとき

自分の作業用には、「ファイル → ワークスペースを指定...」で別の書き込み可能なワークスペースを選びます。その中に授業フォルダ、さらに回次フォルダを作り、PDFやノートを置きます。`__pdf_note_workspace__` はログ、一時ファイル、バックアップなどをアプリが管理する場所なので、資料を置かないでください。

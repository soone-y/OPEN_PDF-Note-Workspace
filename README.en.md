# PDF Note Workspace

A Windows PDF study workspace for viewing PDFs, making non-destructive annotations, and editing notes.

Download the English build from the English GitHub Release. Its Assets provide a full edition and a smaller `Lite` edition. The full edition includes local Office-to-PDF conversion; Lite is PDF-focused.

See the [English documentation](docs/en/README.md). For Japanese, see [README.ja.md](README.ja.md).

PDF Note Workspace

PDF、注釈、ノートを、
一つの文脈で扱う。

PDF Note Workspace は、PDF、注釈、ノート、関連資料を、授業やテーマというひとつの文脈で扱うための、Windows向けローカルワークスペースです。

配布物を入手する セットアップ方法 基本操作

PDFと注釈、ノートを同じワークスペースに並べて扱います。

ファイルではなく、文脈を扱う。

PDFを読むこと、注釈を付けること、ノートを書くこと、資料を整理すること。それらが別々の道具に分かれると、何を読んで何を考えていたのかというつながりが失われます。このソフトは、その作業の流れを一つの場所で保つためのものです。

できること

  • PDFを開き、マーカー・ペン・テキスト・図形で注釈する
  • PDFと並べてノートを書き、資料ごとに整理する
  • 必要に応じて、注釈入りPDFを別ファイルとして書き出す

通常版はDOCX / PPTXをローカルでPDFに変換して扱えます。Lite版はPDF中心の、より小さな配布物です。

使う人の資料と作業を尊重する。

原本のPDFを直接書き換えず、注釈は別のデータとして扱います。外部通信を前提にせず、保存や復元にも配慮します。これは宣伝のための機能ではなく、安心して日々の資料読みを続けるための土台です。

読む順序

  1. For_AI.md — 読取規約、検証方針、基本制約
  2. for_ai/manifest.json — 質問別の読取対象を定義する唯一の経路表
  3. 重要な結論は、経路表が示す一次資料で確認する。

検索・参照用データ

  • for_ai/core/semantic_search_index.json — 質問意図から資料を絞るための検索索引
  • for_ai/core/repository_reference_map.md — 文書・ソース・テスト・公開経路の資料地図
  • for_ai/project_context.xml — プロジェクト文脈と開発動機の構造化データ
  • for_ai/core/documentation_contract.md — AI向け文書の役割と検証規約

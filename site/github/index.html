文書ポータル

人が読む公開文書を、目的別に案内しています。見出しとリンクを整えているため、AIも同じ本文を参照できます。

紹介サイト 配布物を入手する GitHub リポジトリ
  • プロジェクトの概要配布物、通常版とLite版、基本方針を確認する
  • 日本語の文書導入、操作、保存・復元、ファイル形式、トラブル対処の詳細一覧
  • 背景・設計・確認資料設計の考え方、利用判断、根拠と確認範囲を読む
  • ライセンスと第三者通知利用条件と、利用している第三者コンポーネントを確認する

利用目的に応じた案内と確認先（現在地：文書ポータルの案内ページ）

利用者は導入・操作・保存の文書から、高度な利用や検証を行う方は背景資料と公開リポジトリから読み始められます。

利用者 — アプリを導入・使用する
プロジェクトの概要まず用途、通常版・Lite版、基本方針を確認する
→使い方へ
日本語の文書セットアップ、操作、保存・復元、ファイル形式、問題対処を読む
高度利用者・開発を検討する方 — 設計、実装、検証範囲を確かめる
背景・設計・確認資料設計の理由、評価時の見方、公開文書で確認できる範囲を読む
→実体を確認
GitHub リポジトリ実装、テスト、履歴を確認する。ポータルだけでは確認できない事実の確認先
利用条件はライセンスと第三者通知で確認します。これは利用者・高度利用者のどちらにも共通です。アプリを入手する場合は、GitHub Releasesから通常版またはLite版のZIPを選びます。

背景・設計・確認資料は、見出し・表・構造化記法で整理しています。人が読める説明を正本とし、AIも同じ公開資料を参照できます。

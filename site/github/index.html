PDF Note Workspace
文書ポータル

人が読む公開文書を、目的別に案内しています。見出しとリンクを整えているため、AIも同じ本文を参照できます。

紹介サイト 配布物を入手する GitHub リポジトリ
  • プロジェクトの概要配布物、通常版とLite版、基本方針を確認する
  • 使い方・セットアップ導入、操作、保存・復元、ファイル形式、トラブル対処の詳細一覧
  • 背景・設計・確認資料設計の考え方、利用判断、根拠と確認範囲を読む
  • ライセンスと第三者通知利用条件と、利用している第三者コンポーネントを確認する

公開ページの関係

紹介、詳細な文書、公開リポジトリ、配布物は役割を分けて公開しています。

紹介サイトソフトの概要と配布先を知る
→詳しく読む
文書ポータル概要、使い方、背景資料、ライセンスを読む
公開資料を生成・公開
GitHub リポジトリソース、公開資料、履歴を確認する
→配布物
GitHub Releases通常版・Lite版のZIPを入手する

背景・設計・確認資料は、見出し・表・構造化記法で整理しています。人が読める説明を正本とし、AIも同じ公開資料を参照できます。
